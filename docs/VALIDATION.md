# 验证记录与适用范围

本页区分多版本短测、独立原生代码测试与实际游戏长局。安装器 2.1.0 新增七个精确构建的适配，保留 1.25b 已发布的修订版 2 完整 DLL 指纹；本次没有为八个版本各跑一轮长局。

## 2.1.0：八版本适配验证

2026-09-06，通过游戏目录中的武状元版本转换器逐一实际切换八个版本，校验原始指纹、安装补丁并冷启动游戏。测试环境为 3120 × 2080、Direct3D 8，字体栅格字号为 32 像素。每个版本均完成诊断后正常退出。

| 1.26 | IMBA 3.86b AI、洗礼技能学习说明 | 228 | 0 / 0 | 1813 / 7 |

诊断在游戏渲染线程上调用真实字形与换行函数，用字体字符映射确认存在的 1,800 个不同汉字，按“修复 → 原路径 → 修复”顺序分配。A/B 仅临时切换字形分配和 UTF-8 换行的六个编辑位置；批量重建和纹理修复保持启用。因此“原路径”不是完整原版 DLL 对照。测试结束恢复补丁字节及原排版模式，并解除插桩；磁盘上的游戏文件不受诊断修改。

每个版本覆盖两种排版模式中的中文、ASCII、颜色控制码、显式换行、极窄行和空字符串，共 24 个对照样本。修复后的中文消费字节数等于接收字符数的三倍，ASCII 与字符数一致，颜色前缀计入额外 10 字节；换行和极窄行保持进度，所有样本均未消费超过输入长度。八个版本的代码入口均映射为 `r-x`，其中 1.21 / 1.24e 新增的 `.cjk` 节也在实机正确加载。

入口计数只覆盖诊断及随后约五秒。菜单中的批量重建计数为 0，不能据此宣称这些版本的游戏内批量路径已实测；该路径的实际场景验证覆盖 1.21、1.24e、1.26，两种编译器结构另由全部八份原生 x86 测试覆盖。1.21 的 IMBA 创建被游戏明确拒绝为“该地图太大了”，所以改用基础地图；字体修复不移除地图大小或脚本版本限制。

公开数值为 [multiversion-r2.json](evidence/multiversion-r2.json)。代表性真实截图：[1.21 攻击说明](images/1.21.0.6263-tooltip.jpg)、[1.24e 技能说明](images/1.24.4.6387-tooltip.jpg)、[1.26 技能说明](images/1.26.0.6401-tooltip.jpg)。这些是压力测试后的短测截图，不能替代长局、逐帧检查或多人平台兼容性验证。

安装器的 16 组合成测试及配置目录校验通过；全部八份嵌入代码的原生 x86 测试通过；八份本地真实 DLL 在临时副本上的安装、重复安装、恢复和备份验证通过。共享生成器重建结果与公开配置一致，八份输出的 PE 映射、指令边界、分支目标、调用约定锚点及完整恢复指纹检查通过。1.21 / 1.24e 的文件增长和恢复截断额外覆盖了尾部数据保留、篡改拒绝及缺失备份恢复。

## 资源观察

验收区间内有 91 条约每 30 秒一次的数值采样。工作集 296.02–454.47 MiB，起止 394.93 → 314.55 MiB；私有内存 394.68 → 509.86 MiB，增长约 115.18 MiB。句柄 5,155–5,257，线程 59–63。

私有内存增长如实保留，没有同负载原版长局基线，因此不能归因于补丁，也不能宣称无泄漏。`Responding=true` 只作辅助信息，不单独证明无卡死。尚未完成帧率基准、内存泄漏验收或其他渲染后端对照。

公开数值记录为 [summary.json](evidence/long-session-r2.json) 和 [relative-time samples](evidence/soak-r2-samples.jsonl)。采样保留相对经过时间与资源数值，移除了本机进程号和绝对时间。

## 早期失败及修正依据

修订版 1 的短测修正了字形分配和换行，但长局约 20 分钟后仍出现“物品栏”串字。修订版 2 补齐批量失效处理及脏纹理像素重建。详见 [技术分析](ARCHITECTURE.md)。

历史字形压力测试使用字体字符映射确认存在字形的 1,800 个汉字：

| 字体栅格字号 | 原版分配失败 | 修订版 1 分配失败 |
|---|---:|---:|
| 16 像素 | 0 | 0 |
| 24 像素 | 124 | 0 |
| 32 像素 | 185 | 0 |

这是字号对照，不是三个显示分辨率的整局测试。该历史数据只能支持修订版 1 的分配修正；修订版 2 保留同样字节，但不能用这张表替代新增渲染路径的长局证据。

开发阶段的实验插桩曾造成崩溃，包括一处原型返回地址落在指令中间。最终代码已修正并验证指令边界；这些调试崩溃与后续独立冷启动长局分开，不归因于原始游戏故障。

## 公开安装器重构验证

- 合成文件测试：往返恢复、旧版升级、完整指纹拒绝、编辑位置/最终哈希校验、备份保留和损坏拒绝、缺失备份恢复。
- 文件操作测试：已占用目标、外部修改、并发安装及游戏退出检查。
- 原生 x86 测试：内嵌短代码的空链表/选择性重建、再次失效、寄存器/栈/进位标志、完整纹理清零和保护区。
- 可选本地文件测试：用实际支持的 DLL 在临时副本上安装、升级、回滚；原输入文件保持不变。
- CLI：只读状态检查、标准输出和退出码；发布包哈希校验。
- 本机桌面 GUI 复核：中文启动界面、游戏目录输入、只读检查和状态输出布局正常；正确识别当前修订版 2。未遍历所有 DPI、多屏和语言组合。

测试依赖与复现命令见 [BUILDING](BUILDING.md)。原生测试替代引擎依赖，并不执行完整真实渲染器；自动测试通过与实际游戏场景的结论各有范围。
