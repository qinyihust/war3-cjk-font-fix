# War3 CJK Font Fix

[English](README.en.md)

修复经典版《魔兽争霸 III》在高分辨率下出现的中文提示文字越界、重叠和字形串用。补丁修改 `Game.dll` 的字体缓存与换行路径，安装后正常启动游戏即可，无需常驻注入工具或切换窗口。

**当前仅支持经过完整文件指纹验证的 1.25.1.6397 构建。** 相同版本号的其他文件、1.24/1.26/1.27、重制版以及第三方修改过的 DLL 均不能据此认定兼容。安装器会拒绝未知文件。

## 下载与安装

从 [Releases](https://github.com/qinyihust/war3-cjk-font-fix/releases) 下载 Windows ZIP，解压后：

1. 退出所有魔兽争霸 III 进程。
2. 打开 `War3FontFix.exe`，浏览到包含 `Game.dll` 的游戏目录。
3. 点击“检查文件”，确认是支持的原版或旧补丁版本。
4. 点击“安装 / 升级”，等待文件校验通过，然后正常启动游戏。

工具可以放在任意目录。若与 `Game.dll` 放在同一目录，会自动填入该目录。界面按系统语言显示中文或英文；命令行诊断使用英文。运行需要 Windows 和 .NET Framework 4.x；构建及验证环境见 [构建说明](docs/BUILDING.md)。

如果文件已是当前补丁，重复安装不会再次修改。补丁不会修改地图、字体资源、存档、注册表或游戏分辨率，也不会启动或注入游戏进程。

## 恢复原版

退出游戏，在同一工具中选择游戏目录并点击“恢复原版”。工具逐字节重建并验证原版，**原版备份会保留**。这个版本的备份名称为 `Game.dll.before-fontfix-12516397.bak`。

已有备份必须匹配原版完整 SHA-256，否则拒绝覆盖。备份丢失时，也可以从完整指纹匹配的已知补丁版本重建原版。不能从损坏或未知 DLL 强制恢复；请使用自己的原版备份或安装介质。

## 命令行

在终端使用 `War3FontFix.Cli.exe`，可得到标准输出和退出码。含空格的路径需要引号。

```powershell
.\War3FontFix.Cli.exe --check "C:\Games\Warcraft III"
.\War3FontFix.Cli.exe --apply "C:\Games\Warcraft III"
.\War3FontFix.Cli.exe --restore "C:\Games\Warcraft III"
.\War3FontFix.Cli.exe --self-test "C:\Games\Warcraft III\Game.dll"
.\War3FontFix.Cli.exe --list
```

`--check` 和 `--self-test` 不写入游戏文件。退出码：`0` 成功；`1` 操作失败；`2` 参数错误或文件不受支持。GUI 程序保留相同命令参数，但终端及脚本建议使用独立 CLI 程序。

## 兼容性与验证范围

| 项目 | 当前范围 |
|---|---|
| 游戏文件 | 1.25.1.6397，12,042,240 字节，完整指纹见 [兼容表](docs/COMPATIBILITY.md) |
| 补丁数据 | 修订版 2，11 个位置、102 个实际变化字节 |
| 已知升级路径 | 原版 → 修订版 2；修订版 1 → 修订版 2 |
| 实机长局 | Direct3D 8、3120 × 2080、IMBA 3.86b AI、9 名 AI、45 分 48 秒 |
| 长局结果 | 抽查的技能/物品说明、常驻标签正常，无新增游戏崩溃记录 |
| 尚未验证 | 其他 DLL 构建、渲染后端、字体替换、多人平台及反作弊兼容性 |

补丁落在游戏字体引擎中，不依赖特定 Dota 地图文件。IMBA 是本次复现与验收场景，不代表所有地图都已经测试。1920 × 1080 也不是硬编码的故障阈值；缓存压力取决于实际字号、字形宽度和出现过的字符集合。

公开版安装器经过重构，修补后的 DLL 指纹与此前通过长局的修订版 2 完全一致。本次整理没有重新进行另一轮 45 分钟游戏测试。原有长局和新安装器测试分别记录在 [验证说明](docs/VALIDATION.md)，其中也披露了内存增长和未进行帧率基准的限制。

## 根因与实现

修复四处相互关联的行为：字形缓存淘汰后空间仍不足、UTF-8 换行游标提前推进、批量字符串未处理纹理失效、纹理重用时跳过已缓存字形的像素上传。详见 [技术分析](docs/ARCHITECTURE.md)。

补丁数据在 [`patches/`](patches/) 中维护，并在构建时嵌入程序；程序不会加载旁边可任意替换的补丁定义。已有构建的指纹校验不会因添加版本支持而放宽。

## 开发与贡献

以下命令在源码仓库根目录执行；Windows 安装包不包含开发脚本。

```powershell
.\scripts\build.ps1
.\scripts\test.ps1
.\scripts\package.ps1
```

默认测试只使用合成数据和内嵌机器码，不需要游戏 DLL。可选的本地完整文件测试使用自己的游戏文件，并只修改临时副本。详见 [构建与测试](docs/BUILDING.md)、[新增版本支持](docs/PORTING.md)、[贡献指南](CONTRIBUTING.md) 和 [更新记录](CHANGELOG.md)。

问题反馈请附游戏版本、`--check` 输出、分辨率、渲染后端及最小复现步骤。请不要上传游戏 DLL、地图、内存转储或包含个人信息的完整日志。
